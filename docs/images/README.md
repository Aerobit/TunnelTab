# README screenshots

These images are generated by `tests/e2e/readme-shots.js`. Everything in
them is made-up demo data:

- the one connected server is the local `fakessh` development server in
  `-demo` mode (realistic prompt and canned output for `uptime`, `df -h` and
  `docker ps`);
- the other servers use reserved `example.com` names and are added through
  the API without ever connecting.

Regenerate them whenever the UI changes:

```bash
cd tests/e2e
npm ci
npx playwright install chromium
node readme-shots.js
```
